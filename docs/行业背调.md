# 行业背调

---

## 1. 背景

国家组织药品集中带量采购（下称"集采"）、国家医保药品目录、药品批准文号、违规/取消资格名单，分别由联采办、国家医保局、国家药监局等机构发布，彼此独立、格式不一。截至 2026-11，国家集采已到第十二批（见[内蒙古执行第十二批中选结果的通知](https://ylbzj.nmg.gov.cn/xwzx/tzgg/202611/t20261112_2976557.html)）。

本系统把这些来源围绕同一批药品统一组织，提供检索、交叉核验与来源追溯。本背调核实现有方案（官方平台 + 商业数据库）已实现什么、缺什么，以明确本系统的差异点。

## 2. 官方平台

| 平台 | 功能 | 局限 |
|---|---|---|
| 联采办公告栏（上海阳光医药采购网 smpaa.cn） | 各批次集采公告、中选结果、供应清单（PDF 附件）、执行/供应调整提示 | 公告列表 + 附件下载，无结构化检索，无跨源关联，无核验 |
| 国家医保服务平台（fuwu.nhsa.gov.cn） | 医保药品目录查询（甲乙类、备注、谈判药品支付标准）、医保业务 | 单点查询；不整合集采中选结果，不关联违规名单 |
| 各省医保局 / 招采平台 | 本省集采执行公告、挂网价格 | 分散在 30 余个平台，格式不一，无全国口径 |
| 中国药品价格登记系统（2025-12 上线，国家医保局 + 北京市共建） | 企业自主申报登记药品价格，提供价格登记查询，"一地受理、全国共享、全球公开"，服务企业出海定价与国际竞争 | 企业自报的市场价登记制；不覆盖集采中选记录、批文状态，不做跨源核验 |

出处：[北京市医保局公告（2025-12-09）](https://ybj.beijing.gov.cn/zwgk/2020_zfxxgk/2020_xxgkml/202512/t20251209_4330585.html)、[第九批执行提示](https://www.smpaa.cn/xxgk/gggs/2024/03/22/13368.shtml)。

## 3. 商业数据库

| 产品 | 功能（查证） | 模式 |
|---|---|---|
| 摩熵医药 / 易联招采网（pharnexcloud.com） | 药品集中采购数据库：中选单价、药品降幅、品种降幅、区域企业、报量、各省供应量、剂型/治疗领域分布、可视化面板；联动一致性评价库、BE 试验库；定位"评估药品竞争力与集采资格，辅助价格决策" | 企业版/个人版付费，SaaS + 定制咨询 + API |
| 药智网（yaozh.com） | 药品注册/批文、招采、全球注册、资讯；移动端"掌上数据库" | 付费会员 |
| 米内网（menet.com.cn） | 医药市场终端销售数据、行业分析 | 付费 |

出处：[药品集中采购分析（摩熵医药）](https://www.pharnexcloud.com/zixun/kp_48436)、[药智数据 App Store 页](https://apps.apple.com/mo/app/id1025304074)。

**共性**：覆盖广、更新快、分析深（降幅、报量、一致性评价联动）；全部付费、封闭，数据不可下载、脚本不可见；服务对象是药企、投资机构。

## 4. 对比

| 维度 | 官方平台 | 商业数据库 | 本系统 |
|---|---|---|---|
| 数据范围 | 集采公告/目录/挂网价（分散） | 广：集采+注册+全球+销售 | 窄：集采中选+目录+批文+违规 |
| 检索 | 有，单点、分散 | 强：多维筛选、可视面板 | 有：组合检索+详情 |
| 跨源关联 | 无 | 有（一致性评价、BE 等库联动） | 有（四源按药品关联） |
| 价格/降幅分析 | 无 | 强（降幅、报量、区域） | 弱（同品种价差） |
| 矛盾核验 | 内部监测，不公开 | 未见此产品形态 | 有：违规 vs 中选、目录 vs 批文、集采 vs 目录、价差 |
| 来源追溯 | 只有公告文档 | 来源说明级 | 条目级：公告文号 + URL（部分到 PDF 页码） |
| 开放与费用 | 免费，封闭，无下载 | 付费，封闭，不开放数据 | 开源 + 免费 + 数据可下载 |
| 可复现 | 不可 | 不可 | 可：脚本 + 快照 + 验证记录 |
| 数据量/更新 | 权威、及时 | 大而快 | 小，更新依赖人工 |
| 服务对象 | 公众/机构 | 药企、投资机构 | 医院药剂科、媒体、研究者、学生 |

## 5. 差异点

先说整体定位：商业库卖"全、快、深"，官方平台卖"权威、免费"，但两者都不做跨源核验，也都不开放数据。本系统的差异不在数据本身，而在下面几件事，按证据强弱排列。

### 5.1 矛盾核验（最强的差异）

把跨源不一致作为查询输出，而不是让用户自己比对：

- 违规 vs 中选：已取消资格/断供，但中选记录仍"有效"；
- 目录 vs 批文：目录内品种在批文库无有效批文（品种级 + 覆盖率口径）；
- 集采 vs 目录：集采中选但未入医保目录；
- 同品种价差：同规格、同计价单位的跨企业中选价差异。

配套闭环：录入"取消中选资格"公告，触发器自动把对应中选记录置"失效"，并写入状态审计日志。

商业库做价格/降幅分析，未见到把"中选记录 × 违规名单"自动比对的产品形态；官方的执行监测在内部，不公开。核验质量受批文库覆盖与名称匹配规则影响，相关口径在文档中写明。

### 5.2 来源追溯

每条中选记录、目录条目、违规记录通过 `source_announcement_id` 绑定公告（文号、发布机构、日期、原文 URL），目录条目另有 PDF 页码；点任何一条记录都能回到公告原文。

官方只有公告文档，没有"事实条目 ↔ 公告"的绑定；商业库是"数据来源"级说明，不逐条绑定。追溯对象是官方公告级出处，不是全文自动定位。

### 5.3 开源、可复现与口径公开

数据（CSV/SQL）、建库脚本、核验视图全部公开，免费、可下载、可复现，含实跑验证记录；匹配规则与核验口径同样公开，结果可以复算。

官方平台免费但封闭、无数据下载；商业库付费且不开放数据。这里的差异不是"免费"（官方也免费），而是"开源 + 可下载 + 可复现 + 口径可查"合起来的可审计性。

### 5.4 可扩展：支付标准三角核对

同一品种的挂网价、中选价、医保支付标准放一起核对：实际价格超出支付标准的，超出部分由参保人员自担（医保发〔2023〕30号），这类偏离直接关系到患者自付金额。真实事件已有报道（央视调查"集采百元一盒药，药店卖 3960 元"、中新网"药店高价销售集采药，政策红利不容截留"）。目录支付标准已解析 429 条，缺口在谈判药各省挂网价——补齐后即可作为第五类核验落地。

## 6. 结论

- 差异真实存在，强弱有序：**矛盾核验 > 来源追溯 > 开源可复现与口径公开**；
- 与商业库不构成正面竞争：他们卖"全、快、深"，本系统提供"核验、追溯、可复现"；
- 劣势同样明确：数据量、更新速度、分析深度不如商业库，报告与演示中如实说明。
