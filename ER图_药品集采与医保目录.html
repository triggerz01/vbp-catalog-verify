关系与基数说明

关系实体基数实现方式含义 / 核验点
生产企业 → 药品1 : Ndrug.manufacturer_id → manufacturer一个企业生产多个药品
匹配药品 → 中选记录1 : Nselected_item.drug_id → drug（可空）匹配失败本身就是核验结果
包含集采批次 → 中选记录1 : Nselected_item.batch_id → vbp_batch一个批次含多条中选记录
供应于中选记录 → 供应省份1 : Nsupply_province.selected_id → selected_item一条中选记录供应多个省份
来源追溯公告 → 中选记录1 : Nselected_item.source_announcement_id → announcement回溯某条中选记录来自哪个公告 PDF
违规核验（弱）违规记录 ↔ 中选记录M : N企业名 + 药品名 文本匹配找出"已取消资格但供应清单未更新"的品种
目录匹配（弱）医保目录 ↔ 药品N : 1药品名 文本匹配找出"目录内但批文库无有效批文"的品种

关键约束：approval_no（国药准字）、uscc（统一社会信用代码）、batch_no、notice_no 均 UNIQUE；catalog(version, catalog_no) 联合唯一；price CHECK(>0)；category IN('甲','乙')。
来源追溯：图中画出公告→中选记录一条代表线；实际上 selected_item / violation / catalog_entry 等所有事实表均可加 source_announcement_id → announcement 实现来源追溯。
弱关联是本选题"交叉核验"的核心：无外键，靠"企业名+药品名""药品名"文本匹配，对应报告第 4、6.3 节的一致性校验规则。
